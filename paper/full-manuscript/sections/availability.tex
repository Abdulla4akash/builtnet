\section{Data and code availability}

The MIT-licensed software, tests, construction cards and reference tables are available in the \href{https://github.com/Abdulla4akash/builtnet}{builtnet repository} \citep{builtnet2026}. The code revision used here is \texttt{e90714d}. The article source includes scripts, checked aggregate values and the figure and table files. The software and plotting scripts can be inspected without credentials or register records. The table interface accepts membership arrays supplied by the caller under the relevant data-access arrangements. National microdata and the corresponding edge lists are outside this article's inputs. The Danish and Dutch aggregate checks reuse selected numerical evidence from the archived results reported in the companion preprints.
